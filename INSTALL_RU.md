# Установка на Samsung Galaxy S23 FE

## 1. Получите APK

На GitHub откройте репозиторий → **Actions → Build Android APK**. Дождитесь зелёной галочки последнего запуска. В разделе **Artifacts** скачайте `photo-to-prompt-apk`. Если кнопки не видны, включите в браузере «Версия для ПК». Для скачивания войдите в аккаунт GitHub.

В Samsung «Мои файлы» → «Загрузки» откройте скачанный ZIP, распакуйте и нажмите `photo-to-prompt-arm64.apk`. При необходимости разрешите установку из этого источника для «Мои файлы». Разрешение можно отключить после установки. Если Samsung блокирует установку, прочитайте показанное им сообщение; не отключайте защиту целиком без необходимости.

Если Actions показывает красный значок, APK не создан. Откройте неуспешный шаг и передайте его текст ошибки для исправления. Не переименовывайте архив исходников в APK.

## 2. Подключите модель

Откройте приложение → **Модель**. Скачайте **оба** файла через кнопки браузера (примерно 437 и 109 МБ). Дождитесь полного завершения загрузки.

- `SmolVLM-500M-Instruct-Q8_0.gguf` — «Импортировать файл 1».
- `mmproj-SmolVLM-500M-Instruct-Q8_0.gguf` — «Импортировать файл 2».

Приложение проверит файлы. После успешного импорта появится «Модель подключена». На загрузку и импорт оставьте около 1,2 ГБ свободного места. Копии в «Загрузках» после импорта можно удалить вручную: модель останется в приватной папке приложения.

## 3. Разберите фотографию

Выберите фото → «Анализировать на телефоне». Оставьте приложение открытым. Первый запуск может занять несколько минут, телефон может нагреться. При сворачивании анализ отменяется, текущий этап обработки изображения может остановиться не сразу.

EXIF отображается отдельно. Если фото скачано из соцсети или сделано скриншотом, метаданных может не быть. `Not available` означает отсутствие данных, а не ошибку.

Английский разбор ИИ — предположение. Проверьте его, при необходимости исправьте поле промпта и нажмите «Копировать промпт» или «Копировать весь разбор». Модель компактная: подробность и точность ограничены. Визуальное сходство не устанавливает автора фотографии.

После импорта модели можно включить **авиарежим**: всё работает на телефоне. У APK нет разрешения на интернет. Фото и результаты хранятся только в текущем процессе; скопируйте нужный текст до закрытия приложения системой.

## Если не работает

- Не совпадает файл модели: дождитесь завершения загрузки и выберите правильный файл из инструкции.
- Не хватает памяти: закройте другие тяжёлые приложения и повторите.
- Описание неточное или неполное: это ограничение локальной модели; исправьте текст вручную.
- При обновлении написано «Приложение не установлено»: возможно, ключ отладочной подписи изменился после очистки кэша GitHub. Удаление старой версии удалит также импортированные модели; сначала сохраните нужные результаты.
