# Photo to Prompt — offline Android

Первая версия приложения для Samsung Galaxy S23 FE и других устройств Android 9+ с arm64-v8a. Русский интерфейс, английский разбор фотографии и промпт для генерации.

## Возможности

- Выбор одного локального изображения через системный выбор файлов, без доступа ко всей галерее.
- Камера, объектив, фокусное расстояние, диафрагма, выдержка и ISO из EXIF, если они есть. Отсутствующие значения обозначаются `Not available`.
- Размеры, пропорции и палитра по пикселям.
- Локальный визуальный анализ через SmolVLM-500M и llama.cpp: шесть отдельных вопросов о сюжете, композиции, свете, цвете, фокусе, обработке и стиле. Модель загружается один раз на весь анализ.
- Английский промпт собирается из этих шести ответов, затем доступен для редактирования и копирования отдельно или вместе с полным разбором.
- Импорт двух файлов модели с проверкой SHA-256, отмена обработки и удаление данных сеанса.

**Ограничения:** компактная модель не гарантирует полный или точный разбор и может пропустить поля либо выдумать детали. Если она не выделила отдельный промпт, её реальное описание показано как черновик. На конкретном S23 FE скорость и качество ещё нужно проверить. По пикселям нельзя достоверно восстановить точную камеру/объектив или автора. Все визуальные выводы отдельно помечены как предположения. Сравнения со стилями фотографов не означают авторство.

## Скачать APK после сборки

1. Откройте вкладку **Actions** → **Build Android APK**.
2. Выберите последний успешный запуск (зелёная галочка).
3. Внизу, в **Artifacts**, скачайте `photo-to-prompt-apk` (нужен вход в GitHub).
4. Распакуйте ZIP приложением Samsung «Мои файлы» и откройте `photo-to-prompt-arm64.apk`.
5. Полная инструкция: [INSTALL_RU.md](INSTALL_RU.md).

Сборка запускается при изменениях в `main`, а также вручную: **Actions → Build Android APK → Run workflow**. В архиве лежит подписанный отладочный APK для личного тестирования, инструкция, SHA-256 и отчёт Android Lint. Это не публикация в Google Play. При истечении 30-дневного хранения запустите workflow снова.

## Конфиденциальность

В итоговом APK проверяется **полное отсутствие разрешений**, включая INTERNET. В приложении нет сетевых клиентов, аналитики, рекламы, WebView или сервера. Фото и результат находятся в памяти процесса, история на диск не записывается. В приложение импортируются только файлы модели в приватную папку, исключённую из резервного копирования и переноса. Геолокация, серийные номера и имя владельца из EXIF не выводятся.

Скачивание модели происходит в отдельном браузере, только по нажатию пользователя. Приложение не передаёт ему фото. При копировании результат попадает в системный буфер обмена, которым управляет Android. Настройки синхронизации клавиатуры, буфера обмена и исходной галереи находятся вне приложения.

## Модель

Поддерживается конкретная пара [SmolVLM-500M-Instruct-Q8_0 и mmproj Q8_0](https://huggingface.co/ggml-org/SmolVLM-500M-Instruct-GGUF/tree/72e9860) от ggml-org, около 546 МБ вместе. Ссылки и хеши зафиксированы в `ModelStore.java`. Модель не включена в репозиторий или APK. Нельзя подменять только один файл другой моделью. Более крупные модели в этой версии не поддерживаются.

## Сборка

GitHub Actions устанавливает Java 17, Gradle 8.11.1, Android SDK 35, NDK 27.2.12479018 и CMake 3.22.1. Затем извлекает llama.cpp по фиксированному коммиту `af50f2f248b475d9760f8e67503d01c0f194f5f4`, запускает unit-тесты, Android Lint, сборку APK и проверку реального манифеста, подписи и выравнивания APK.

Для локальной сборки: установите перечисленные инструменты, выполните `python3 scripts/prepare_vendor.py`, `python3 scripts/collect_licenses.py`, затем `gradle testDebugUnitTest lintDebug assembleDebug`. Можно открыть проект в Android Studio и указать установленный SDK. Бинарный Gradle wrapper не включён; версия Gradle задаётся явно в Actions.

Отладочный ключ сохраняется в кэше Actions, чтобы сборки обычно устанавливались как обновления. При удалении/вытеснении кэша появится новый ключ: потребуется удалить старую установку, что также удалит импортированные модели и несохранённый сеанс. Для долговременного распространения нужен отдельный постоянный ключ подписи; секреты в проект не включены.

## Проверка на телефоне

1. Импортировать оба файла модели и убедиться, что хеши приняты.
2. Включить авиарежим, открыть фото и выполнить анализ.
3. Проверить оригинальный JPEG с EXIF и скриншот без EXIF: выдуманных значений в разделе данных файла быть не должно.
4. Проверить портретное фото с EXIF-поворотом, PNG и повторный выбор фото.
5. Проверить копирование и правки промпта, отмену и новый запуск, сворачивание приложения, удаление модели.
6. Сопоставить описание с фото. Компактный ИИ может ошибаться; успешная сборка не доказывает точность анализа.
